Same build, different host

nginx serves the files. Node does not stay in the image.

The first Docker stage compiles Angular. The second stage copies only dist/angular-cicd-demo/browser into nginx. A refresh works because nginx tries the file, then falls back to index.html.

  1. Build image

    docker build -t angular-cicd-demo:local .

  2. Run it

    docker run --rm -p 8080:80 angular-cicd-demo:local

  3. Prove the router

    Open http://localhost:8080/docker and refresh the page.

What to say in the interview

“I use a multi-stage image so production does not contain the Angular compiler or node_modules. nginx is the process that stays running. I tag the image with the commit SHA, not only latest, so a rollback is a redeploy of a known tag. GitHub Pages is the free public URL for this demo. Docker Desktop is the free way to practice the container.”
