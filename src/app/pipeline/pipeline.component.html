What to say in the interview

“A pull request installs dependencies with npm ci, runs unit tests in a headless browser, and produces a production build. Merging to main uploads that artifact to GitHub Pages. The Angular router uses path URLs, so the host must fall back to index.html. Secrets stay in the CI secret store. I roll back by redeploying the previous artifact.”
