Where the static files go

Angular production is a folder of files.

ng build writes HTML, CSS, and JavaScript. Any static host can serve them. The host must return index.html when the path is an Angular route.

Private repository, public website

GitHub Actions can test a private repo on the free plan. GitHub Pages on that same free plan publishes only a public repository. Cloudflare Pages, Netlify, Vercel, Firebase Hosting, and Azure Static Web Apps can build a private repo. The website URL is still public. That is the normal split: private source, public frontend.
